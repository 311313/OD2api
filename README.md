# OD2api

把上游 AI 编码服务的账号池包装成 OpenAI 兼容接口。

多个账号轮换调度：按余额、日限额、请求间隔选号；触发限流的账号自动进入冷却，冷却结束后重新参与调度。下游配置一个 Base URL 和 API Key 即可接入，无需感知账号数量。

## 功能

- **账号池调度**——按余额、日限额、请求间隔选号；失败自动冷却与恢复
- **粘性会话**——同一对话固定路由到同一账号，复用上游缓存
- **按模型计价**——各模型单价独立测量（含缓存折扣），请求日志记录每次消耗
- **管理面板**——账号、分组、密钥、请求日志、统计
- **容器化部署**——Docker Compose 启动，含健康检查与自动回滚
- **自动更新**——推送代码后宿主机定时拉取并重建，面板可手动触发

## 部署

```bash
docker compose up -d --build
```

面板默认在 `http://127.0.0.1:7890`。管理令牌首次启动时随机生成，面板设置页可查看与轮换。

## 目录

```
src/          网关服务（Node 24 + Express + node:sqlite）
public/       管理面板（原生 HTML/JS，无构建步骤）
docs/         计费测量方法、运维记录
scripts/      部署、备份、回归测试
```

## 配置

环境变量见 `.env.example`，均为可选。数据库位于 `data/`，容器重建不丢失。

## 说明

- 上游客户端为闭源实现，接口行为经抓包分析确定，详见 `docs/`
- 上游协议变更需同步适配，`docs/incidents.md` 记录已知问题
